What this is

        

          EMS Flasher writes Game Boy ROMs and save files to the
          EMS GB USB smart card 64M, the USB flash cartridge
          sold as the “USB 64M smart card”. It runs entirely in the browser
          over WebUSB: no drivers, no install, and nothing is uploaded, because
          the page has no server behind it.
        


        
What you can do with it

        
    
          
  • 
            Flash a ROM — drop a .gb or
            .gbc file on the page and write it to either 4 MiB
            bank. Homebrew, translations, your own builds.
          
    • 
          
  • 
            Run LSDJ — chiptune musicians use this cart for
            Little Sound Dj and nanoloop. Write the ROM, then back up
            the .sav that holds your songs before you overwrite
            anything.
          
    • 
          
  • 
            Back up and restore saves — the cart has 128 KiB
            of SRAM shared by both banks. Dump it to a file, restore it later.
          
    • 
          
  • 
            Put several games on one bank — the cart menu
            lists every ROM it finds, so a bank can hold a whole shelf. Add and
            remove games one at a time, or pull a single one back out as a
            working ROM file.

Questions


        
Which browsers work?

        

          Chrome, Edge, Opera, and Chrome on Android with an OTG cable. Firefox
          and Safari have both declined to implement WebUSB, so they cannot
          talk to USB devices at all. On those, use the command line version:
          npm install -g ems-flasher-js.
        


        
Do my ROMs get uploaded anywhere?

        

          No. There is no backend. The page reads the file locally and writes
          it to the cart over USB; the network tab stays empty.
        


        
Which cartridge does it support?

        

          The EMS 64 Mbit USB flash cart for Game Boy, USB ID
          4670:9394 — 64 Mbit of flash as two 4 MiB banks plus
          128 KiB of save RAM. Other flash carts speak different protocols and
          are not supported.
        


        
Is it free?

        

          Yes, MIT licensed and open source. It is a port of the original C
          flasher by Mike Ryan, whose reverse engineering — with David Wendt
          JR. and Jamie Bainbridge — everything here is built on.
